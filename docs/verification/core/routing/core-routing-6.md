# core-routing-6

- `core-routing-6` After an explicit application capability refusal, a read tries another recognised company before same-company routes within the existing availability and knowledge band.

[Area and shared preconditions](README.md).

## Driving it with the harness

`test/integration/refusal_vendor_diversity_test.exs` points three fixture hostnames at owned HTTP listeners. Priority fixes the ranking. Upstream hit counts prove that the independent route answers in two dispatches without calling the sibling. A two-dispatch execution envelope also exercises the public request pipeline. Controls preserve sibling fallback, unknown-host order and rate-limit order.

- **core-routing-6.** Require the independent route result and exactly two upstream sends, with no sibling send.

Run with `mix test test/integration/refusal_vendor_diversity_test.exs --include integration`.
