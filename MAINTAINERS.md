# Maintainers

Lasso RPC is currently maintained by:

- Jackson Ernst ([@jaxernst](https://github.com/jaxernst))

The maintainer owns release decisions, repository policy, security coordination,
and final review of changes. CODEOWNERS requests this maintainer's review across
the repository; it does not replace CI, contributor review, or branch protection.

Material behavior changes should begin with a GitHub issue so compatibility,
operational impact, and evidence expectations are clear before implementation.
Routine fixes and documentation improvements may go directly to a pull request.
Security reports follow [SECURITY.md](SECURITY.md).

The current maintainer updates this file and `.github/CODEOWNERS` when project
ownership changes.
